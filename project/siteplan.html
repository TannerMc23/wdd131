First Flight Disc Golf - Site Plan

Author: Tanner McMillan

WDD 131

Site Name

First Flight Disc Golf

I chose this name because it represents a beginner's first throw ("First Flight"), making the site feel welcoming and beginner friendly.

Site Purpose

The purpose for First Flight Disc Golf is to help beginners or anyone learn more about the sport of disc golf. The website will teach:

  • Basic rules
  • Simple throwing techniques
  • Beginner gear recommendations
  • Tips for improving accuracy and distance

The website will also include simple interactive JavaScript elements to engage learners.

Scenarios

  • "What type of disc should I start with as a beginner?"
  • "What are the basic throwing techniques I need to learn?"
  • "How do I understand disc numbers like speed, glide, turn and fade?"

Color Scheme

Main Colors:

  • Forest Green - Headings, Accents
  • Sky Blue - Navigation, emphasis
  • Soft White - Background
  • Warm Orange - Buttons, highlights

This color scheme represents nature, sky and energy-fitting for disc golf.

Typography

  • Headings: Montserrat
  • Body Text: Open Sans

Clean and modern fonts that keep the site readable and beginner-friendly.
